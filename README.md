# C++ OOP Lab Exercises (UNC302)

A collection of C++ lab exercises organised by assignment (A.1–A.9). The source files cover introductory programming, object-oriented programming concepts, polymorphism and file handling.

## Assignments

| Assignment | Topics covered |
|---|---|
| A.1 | C++ basics: input/output, arithmetic, conditional logic, operators and simple problem-solving exercises. |
| A.2 | Structures and classes, student records, data members, access control and class methods. |
| A.3 | Pointers and the `this` pointer, friend functions/classes, arrays of objects and passing/returning objects. |
| A.4 | Constructors, arrays of objects, destructor behaviour and dynamic memory allocation. |
| A.5 | Inheritance, access modes, multilevel and multiple inheritance, and derived-class examples. |
| A.6 | Class-based examples involving constructors, friend functions, complex numbers, library records and account transactions. |
| A.7 | Polymorphism, virtual and abstract classes, function overloading, operator overloading and matrix operations. |
| A.8 | File handling with text and binary I/O, file streams, character I/O and file pointers. |
| A.9 | Additional file-handling exercises covering numeric data, counting characters, copying files and file-pointer operations. |

## Repository contents

Each assignment folder contains individual `.cpp` exercise files. These are standalone lab examples rather than one combined application.
